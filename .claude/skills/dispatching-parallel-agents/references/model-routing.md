# Model routing for dispatches

The current canonical policy is `~/.claude/references/model-guide.md`. Read it when choosing a model or effort level; this file is a compatibility pointer for existing agent references.

## Model-Specific Steering

State the outcome, owned files, constraints, dependencies and acceptance evidence on every model. Use Haiku for bounded mechanical work with complete inputs, Sonnet for clear implementation, Opus for ambiguous work/review, and Fable when stronger reasoning or long-horizon autonomy is useful. Use supported effort settings rather than thinking incantations. Resolve provider/host overrides, then explicit dispatch model, agent frontmatter, then inherited parent model. Do not infer a version from an alias on a gateway.
