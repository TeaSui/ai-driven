# Session scope

Keep track of the active outcome, accepted corrections, constraints, completed work and remaining work. Treat mid-task user messages as steering unless the user clearly cancels or replaces the goal. Answer brief status/questions and continue authorized work. Reassess routing if the scope adds a domain or trust boundary. Suggest a separate session only when it materially helps a large unrelated task; do not force a confirmation for ordinary clarifications or follow-up fixes.
